🧪 Suite de Pruebas de Responsividad

Casos de prueba para validar el diseño responsive de la página de producto

Simular breakpoint:

TC-001: Cabecera Responsive

Mobile Tablet Desktop

Validar que la cabecera se adapta correctamente a todos los tamaños de pantalla.

✅ ASSERT-001: Logo visible en móvil

  • El logo debe ser visible sin necesidad de scroll horizontal
  • El tamaño del logo debe ser apropiado (entre 100px y 150px de ancho)
  • Verificar con: document.querySelector('.logo').offsetWidth

✅ ASSERT-002: Navegación en móvil

  • Los elementos de navegación deben ser accesibles
  • El menú puede colapsarse en un botón hamburguesa
  • Los enlaces deben tener un tamaño mínimo de toque de 44x44px
✓ Logo visible TC-001-01
✓ Menú accesible TC-001-02
✓ Sin overflow TC-001-03

TC-002: Grid de Productos - Flexbox vs CSS Grid

Mobile Tablet Desktop

Validar que el grid de productos usa la técnica correcta según el patrón arquitectónico.

✅ ASSERT-003: Layout unidimensional con Flexbox

  • La navegación principal debe usar Flexbox para distribución horizontal
  • Los elementos del menú deben distribuirse uniformemente
  • Verificar con: getComputedStyle(nav).display === 'flex'

✅ ASSERT-004: Layout bidimensional con CSS Grid

  • La sección de productos relacionados debe usar CSS Grid
  • El grid debe tener columnas responsivas que se ajusten al breakpoint
  • Verificar con: getComputedStyle(grid).display === 'grid'

✅ ASSERT-005: Breakpoints de grid

  • Mobile: 1 columna (100% ancho)
  • Tablet: 2 columnas (50% cada una)
  • Desktop: 3-4 columnas (25-33% cada una)
✓ Flexbox en nav TC-002-01
✓ Grid en productos TC-002-02
✓ Breakpoints OK TC-002-03

TC-003: Pie de Página Responsive

Mobile Tablet Desktop

Validar que el footer se adapta correctamente manteniendo la legibilidad.

✅ ASSERT-006: Distribución de columnas

  • Mobile: columnas apiladas verticalmente
  • Tablet: 2 columnas
  • Desktop: 3-4 columnas en fila

✅ ASSERT-007: Espaciado consistente

  • El padding debe ser suficiente (mínimo 16px)
  • Los enlaces deben tener área de toque adecuada
  • El texto debe ser legible sin zoom
✓ Columnas apiladas TC-003-01
✓ Espaciado OK TC-003-02
✓ Links accesibles TC-003-03

TC-004: Errores Comunes de CSS

Validar que se evitan los errores clásicos de maquetación.

✅ ASSERT-008: Collapsing margins

  • Verificar que los márgenes colapsan correctamente entre elementos
  • El header debe tener separación clara del contenido principal
  • Usar padding o overflow: hidden en contenedores cuando sea necesario

✅ ASSERT-009: Altura de contenedores

  • Los contenedores flex/grid deben tener altura correcta
  • Verificar con: element.offsetHeight > 0
  • El contenido no debe desbordar fuera del contenedor padre

✅ ASSERT-010: Imágenes responsive

  • Las imágenes no deben exceder el ancho de su contenedor
  • Usar max-width: 100% y height: auto
  • Verificar: img.naturalWidth <= img.parentElement.offsetWidth
CSS Reset aplicado: normalize.css v8.0.1 está incluido para eliminar inconsistencias entre navegadores.
